## Featured Work

### [An IoT-Based Infrastructure Model for Reducing Urban Light Pollution](https://github.com/Reyadh418/Light-Pollution)
**Research · IoT · Edge AI · Data Analysis · Embedded Systems**

A research repository and open-access study proposing a smart-lamppost infrastructure model for reducing urban light pollution in Dhaka. The work combines an empirical photometric survey, controlled luminaire experiments, reproducible Python analysis, and a four-zone IoT architecture based on sensor fusion and edge intelligence.

**Highlights:**

- Curated field measurements across 13 urban sectors in Dhaka.
- Controlled experiments examining mounting geometry, LED spectrum, optical shielding, and window glazing.
- ESP32-S3-based sensor architecture integrating environmental, motion, optical, and power telemetry.
- Predictive look-ahead using low-latency ESP-NOW communication.
- Reproducible datasets, scripts, hardware specifications, manuscript source, and DOI-backed research artifacts.

This project represents my interest in applying software and engineering to environmental, civic, and infrastructure challenges.

### [freeChat](https://github.com/Reyadh418/freeChat)
**Privacy Engineering · Web Cryptography · Node.js · WebSockets · PWA**

A zero-knowledge, end-to-end encrypted private messenger designed to keep message plaintext and private keys on users’ devices. The project applies native W3C Web Crypto APIs, real-time WebSockets, secure key handling, and a dual-mode persistence architecture.

**Highlights:**

- ECDH P-256 key agreement and AES-256-GCM message encryption.
- Non-extractable private keys and encrypted client-side key storage.
- Safety numbers and fingerprints for detecting key substitution and potential MITM attacks.
- Socket.IO real-time messaging with authentication and authorization checks.
- Local development mode with an optional Supabase PostgreSQL adapter.
- Automated verification covering cryptography, authorization boundaries, rate limiting, and security hardening.

This project demonstrates my ability to explore security concepts and translate them into a working full-stack application.

### [Drive Control Center](https://github.com/Reyadh418/Drive-control-center-project)
**Full-Stack Web Development · Google APIs · SQLite · Data Visualization**

A local-first dashboard for connecting multiple Google Drive accounts, building a searchable SQLite metadata index, managing files, and understanding storage usage from one interface.

**Highlights:**

- OAuth 2.0 integration with the Google Drive API.
- Multi-account file indexing and cross-account file operations.
- Folder-tree navigation, breadcrumbs, history controls, and thumbnail caching.
- Storage analytics, largest-file discovery, and duplicate detection using MD5 checksums.
- Privacy-conscious local storage of indexed data and credentials.

The project reflects my interest in building useful productivity tools around real APIs and structured data.

### [Aurum Chess](https://github.com/Reyadh418/Chess-Game-Project)
**Algorithms · Game Logic · Frontend Engineering · Accessibility**

A browser chess experience built with vanilla HTML, CSS, and JavaScript. It supports player-versus-AI and local pass-and-play modes, legal move enforcement, time controls, Stockfish analysis, post-game review, keyboard interaction, and responsive interface design.

**Highlights:**

- Rule-aware chess engine supporting castling, en passant, promotion, check, and time controls.
- Stockfish-powered analysis with a built-in minimax fallback.
- Move review, evaluation visualization, keyboard controls, and accessibility-focused UI states.
- Deployed as a playable web application with GitHub Pages.

### [Cricket Tournament Statistics](https://github.com/Reyadh418/cricket-tournament-stats)
**C/C++ Fundamentals · Data Structures · Algorithms · Numerical Reasoning**

A command-line tournament statistics system for recording player performances, calculating batting averages and strike rates, ranking players, and persisting records. The project addresses domain-specific edge cases such as undefined batting averages and floating-point division, while incorporating recursive analysis requirements.
